# T0.3 Feature-модули и фабрика приложения

**Фаза:** P0 · **Слой:** backend, python · **Зависит от:** T0.2 · **Размер:** L

## Контекст
Слои разложены по типам (`routers/`, `schemas/`, `repositories/`, `dependencies/`). При росте до 10+ фич это превращается в прыжки по всему дереву. Репозиторий сам делает `commit()`, поэтому две операции в одной транзакции не собрать.

## Цель
Код сгруппирован по фичам, у каждой фичи слои router → service → repository; приложение создаётся фабрикой с явными настройками.

## Что сделать
1. src-layout: `backend/src/app/`.
2. `core/`: `settings.py`, `db.py` (engine, session), `security.py`, `errors.py`.
3. `modules/auth/`, `modules/users/`, `modules/notes/` (в P2 станет `pages`), в каждом: `router.py`, `service.py`, `repository.py`, `models.py`, `schemas.py`, `dependencies.py`.
4. `service` — новый слой: бизнес-правила и граница транзакции. Router вызывает service, service — repository. `commit()` только в service (или в unit-of-work), не в repository.
5. `create_app(settings) -> FastAPI` в `main.py`. Тесты создают своё приложение со своими settings, без `monkeypatch` глобалов.
6. Settings по окружениям: `APP_ENV=local|test|staging|prod`, `pydantic-settings`, валидация при старте (на prod — `JWT_COOKIE_SECURE=true`, иначе приложение не стартует).
7. Убрать `alembic check` из lifespan (миграции станут release-шагом в T1.2) или оставить только для `local`.
8. Репозиторий описать через `Protocol` — сервис зависит от интерфейса, тест может подставить fake.

## Python-фокус
- `typing.Protocol` и структурная типизация vs наследование от ABC.
- Почему глобальный объект при импорте модуля мешает тестам.

## Критерии приёмки
- [ ] Структура как в `docs/ROADMAP.md` §2; импорты не циклические
- [ ] Router не импортирует SQLAlchemy-модели и сессию напрямую
- [ ] `create_app()` используется и в `uvicorn`, и в тестах
- [ ] Неверная конфигурация prod валит старт с понятной ошибкой
- [ ] Все старые тесты зелёные

## Частые ошибки
| Антипаттерн | Почему плохо |
| ----------- | ------------ |
| `commit()` в репозитории | транзакцию из двух операций уже не собрать |
| Глобальный `settings = Settings()` при импорте | тесты не могут подменить конфиг |
| Service принимает `Request` / возвращает `HTTPException` | бизнес-логика привязана к HTTP, её не вызвать из воркера |
