# T0.2 Инструменты Python: uv, ruff, mypy, pre-commit

**Фаза:** P0 · **Слой:** backend, python · **Зависит от:** T0.1 · **Размер:** M

## Контекст
Сейчас `requirements.txt` с транзитивными зависимостями вперемешку, ruff-конфиг минимальный, типы не проверяются.

## Цель
Окружение ставится одной командой с нуля, а код проверяется линтером, форматтером и строгим mypy.

## Что сделать
1. [uv](https://docs.astral.sh/uv/): `backend/pyproject.toml` с прямыми зависимостями, группа `dev` (pytest, mypy, ruff…), `uv.lock` в git.
2. Зафиксировать версию Python (`requires-python`, `.python-version`).
3. ruff: `select` минимум `E, F, I, UP, B, SIM, ASYNC, S` (`S` — безопасность, `ASYNC` — блокирующие вызовы в async-коде). `ruff format` вместо ручного форматирования.
4. mypy `strict = true` + плагин pydantic. Ошибки исправить; временные `# type: ignore[code]` — только с кодом ошибки и записью в `docs/tech-debt.md`.
5. pre-commit: ruff, ruff-format, проверка на большие файлы и приватные ключи (mypy — в CI, чтобы коммит был быстрым).
6. Скрипты запуска (`npm run local` и т.п.) заменить на `uv run ...` в `Makefile` или `justfile`.

## Python-фокус
- Чем прямые зависимости отличаются от lock-файла и зачем нужны оба.
- `strict` mypy: `Optional`, утечки `Any`, generics у `list` / `dict`, типизация `Depends` через `Annotated`.

## Критерии приёмки
- [ ] `uv sync && uv run pytest` работает с нуля на чистой машине
- [ ] `uv run ruff check . && uv run ruff format --check . && uv run mypy src` — чисто
- [ ] `pre-commit run --all-files` зелёный
- [ ] `requirements.txt` удалён
