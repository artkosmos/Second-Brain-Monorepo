# T11.2 Embeddings, гибридный поиск, reranking

**Фаза:** P11 · **Слой:** backend, system-design · **Зависит от:** T5.4, T6.1 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- pgvector; чанкинг блоков: ADR по стратегии (по блоку / по N токенов с перекрытием / по заголовкам); **размер чанка выбирается по eval, а не по интуиции** — мини-набор из 20 вопросов (заготовка для T11.4) прогоняется на 2–3 вариантах.
- Embeddings считает потребитель outbox-событий (T5.4): пересчёт только изменённых чанков (по хэшу содержимого); батчинг запросов к провайдеру; лимит параллелизма `Semaphore`.
- Таблица `chunks (id, page_id, block_id, workspace_id, content_hash, text, embedding vector(N), model, created_at)`; HNSW-индекс; фильтр по `workspace_id` и правам **до** векторного поиска, не после (иначе top-k «съедается» чужими страницами).
- Гибридный поиск: FTS (T6.1) + вектор, объединение через Reciprocal Rank Fusion; веса — параметры.
- Reranking: второй этап над top-50 — cross-encoder локально (`sentence-transformers`, маленькая модель) или rerank-эндпоинт провайдера; ADR с замером latency и качества на eval-наборе.
- Query rewriting: короткий запрос пользователя → 1–2 переформулировки дешёвой моделью (HyDE или multi-query), объединение результатов; включается флагом (T9.5).
- Переиндексация при смене модели: фоновая задача с прогрессом, две колонки / две таблицы на время миграции, переключение атомарно.

## Frontend
- Переключатель «по словам / по смыслу / гибрид» в поиске; подсветка, почему найдено (совпадение слов или семантика).

## Python-фокус
- `numpy` не нужен — всё в SQL; но полезно понять, что такое cosine distance и почему нормализуют векторы. Батчинг и backpressure в consumer'е.

## Критерии приёмки
- [ ] Правка страницы → обновлённые embeddings в пределах SLA (например, 30 с на staging); тест с фейковым провайдером
- [ ] Вопрос перефразом находит нужную страницу (кейсы из eval-набора, recall@5 не ниже согласованного порога)
- [ ] Пользователь без доступа к странице не получает её чанки даже при идеальном семантическом совпадении (тест)
- [ ] Отчёт: recall@5 и latency p95 для FTS / вектор / гибрид / гибрид + rerank на одном наборе
- [ ] Смена модели embeddings не ломает поиск во время переиндексации
