# T6.1 Full-text search в Postgres

**Фаза:** P6 · **Слой:** backend, frontend · **Зависит от:** T2.3 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- `tsvector` по заголовку (вес A) и тексту блоков (вес B).
- Конфиги `russian` + `english` (или `simple` + `unaccent`).
- GIN-индекс; `websearch_to_tsquery`; ранжирование `ts_rank_cd`; сниппеты `ts_headline`.
- Поиск с учётом прав и без удалённых страниц; keyset-пагинация результатов (T2.5).

## Frontend
- Страница поиска, подсветка совпадений, фильтры (workspace, автор, дата).

## Критерии приёмки
- [ ] `EXPLAIN ANALYZE` — Bitmap Index Scan по GIN
- [ ] Морфология работает: «заметки» находит «заметка»
- [ ] Страница без прав не попадает в выдачу
