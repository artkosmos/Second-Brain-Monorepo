# T6.4 Асинхронная индексация

**Фаза:** P6 · **Слой:** backend, frontend, system-design · **Зависит от:** T5.4, T6.1 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Обновление поискового индекса через outbox-потребителя (если `tsvector` хранится отдельно от блоков).
- Поле `indexed_version` на странице.
- Переиндексация всего workspace задачей в очереди.

## Frontend
- Если страница ещё не проиндексирована — метка «индексируется» в результатах.

## Критерии приёмки
- [ ] ADR: где система eventually consistent и какая задержка допустима
- [ ] Переиндексация не блокирует работу пользователей
