# T6.3 Backlinks и @mentions

**Фаза:** P6 · **Слой:** backend, frontend · **Зависит от:** T5.4 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Блок-ссылка и inline-упоминание страницы.
- Таблица `page_links` (from, to) пересчитывается потребителем события `page.updated` из outbox.
- `GET /pages/{id}/backlinks`.

## Frontend
- `@` в редакторе — автодополнение страниц.
- Секция «Ссылки на эту страницу»; ссылка на удалённую страницу показывается как недоступная.

## Критерии приёмки
- [ ] Backlinks появляются после сохранения с задержкой < 2 с
- [ ] Пересчёт идемпотентен
