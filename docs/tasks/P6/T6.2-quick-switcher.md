# T6.2 Quick switcher (Cmd+K)

**Фаза:** P6 · **Слой:** frontend, backend · **Зависит от:** T6.1 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- `pg_trgm` + GIN по заголовкам для нечёткого поиска с опечатками.
- Лёгкий эндпоинт (только id / title / путь), ответ < 50 мс.

## Frontend
- Модалка по Cmd/Ctrl+K: debounce, отмена устаревших запросов (`AbortController` / `signal` из TanStack Query).
- Навигация стрелками, `role="combobox"`, недавние страницы при пустом запросе.

## Критерии приёмки
- [ ] Быстрый ввод не показывает «прыгающие» устаревшие результаты
- [ ] Полностью работает без мыши
- [ ] Опечатка в одну букву находит страницу
