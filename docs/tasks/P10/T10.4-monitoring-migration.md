# T10.4 Мониторинг и переезд с PaaS

**Фаза:** P10 · **Слой:** infra · **Зависит от:** T10.1, T9.1 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Infra
- Prometheus + Grafana + Loki (логи) + alertmanager (Telegram или email) на VPS либо Grafana Cloud.
- Алерты по SLO, диску, бэкапам, сертификатам; uptime-проверка снаружи.
- План и выполнение переезда prod с PaaS: DNS TTL, окно, проверка, откат.

## Критерии приёмки
- [ ] Тестовый алерт приходит
- [ ] Prod работает на VPS
- [ ] Решение по PaaS (выключить или оставить резервом) — в ADR
