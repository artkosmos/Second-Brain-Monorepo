# T10.2 Деплой без простоя

**Фаза:** P10 · **Слой:** infra, system-design · **Зависит от:** T10.1 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Infra
- Деплой из GitHub Actions по SSH (или pull-модель).
- Rolling или blue-green двух инстансов API за Caddy с проверкой `ready` перед переключением.
- Откат одной командой.

## Backend
- Expand / contract миграции: добавить колонку → писать в обе → backfill задачей → читать из новой → удалить старую отдельным релизом.
- Линтер опасных миграций (`squawk` или правила в CI).

## Критерии приёмки
- [ ] Непрерывный k6 во время деплоя — 0 ошибок
- [ ] Переименование колонки проведено за 3 релиза без простоя
