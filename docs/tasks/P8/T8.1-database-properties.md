# T8.1 Database-страница и свойства

**Фаза:** P8 · **Слой:** backend, frontend, python · **Зависит от:** T2.3 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- `databases`: схема свойств (`text | number | select | multi_select | date | checkbox | relation | url`).
- Строки базы = страницы с `properties` JSONB.
- Валидация значений по схеме через discriminated union.
- Изменение схемы (переименовать / удалить / сменить тип) с миграцией значений задачей в очереди.

## Frontend
- Создание базы, добавление свойств, редактирование ячеек по типу (дата-пикер, select с цветами).

## Критерии приёмки
- [ ] Невалидное значение → 422 с указанием свойства
- [ ] Смена типа `text → number`: поведение для нечисловых значений описано и покрыто тестом
