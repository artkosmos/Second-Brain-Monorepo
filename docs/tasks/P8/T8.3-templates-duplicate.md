# T8.3 Шаблоны и дублирование

**Фаза:** P8 · **Слой:** backend, frontend · **Зависит от:** T8.1, T5.3 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Дублирование страницы с поддеревом и блоками: маленькое — в одной транзакции, большое — задачей в очереди с прогрессом.
- Шаблоны страниц и строк базы.

## Frontend
- «Дублировать», «Создать из шаблона», галерея шаблонов.

## Критерии приёмки
- [ ] Дубль не ссылается на исходные id: ссылки внутри поддерева переписаны
- [ ] Дублирование 1000 страниц не блокирует API
