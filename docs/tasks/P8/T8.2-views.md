# T8.2 Представления table / board / calendar

**Фаза:** P8 · **Слой:** backend, frontend · **Зависит от:** T8.1 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Сохраняемые views: тип, фильтры, сортировки, группировка, видимые колонки.
- Фильтры — дерево условий `and / or`, компилируется в SQLAlchemy-выражения по JSONB с белым списком операторов.
- GIN или expression-индексы под частые фильтры; keyset-пагинация.

## Frontend
- Table с виртуализацией строк.
- Board (kanban) с drag-and-drop по select-свойству.
- Calendar по date-свойству.
- Фильтры и сортировки в UI.

## Критерии приёмки
- [ ] Тесты на SQL-инъекции через имена свойств и значения фильтров
- [ ] Перемещение карточки на board = изменение свойства с optimistic update
