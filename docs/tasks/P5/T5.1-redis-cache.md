# T5.1 Redis и кэш

**Фаза:** P5 · **Слой:** backend, system-design · **Зависит от:** P2 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Redis в compose и на PaaS (Upstash или managed); клиент `redis.asyncio`.
- Cache-aside для дерева страниц и эффективных прав (T4.2).
- Ключи с версией (`tree:v3:{workspace_id}`), TTL, инвалидация на запись.
- Защита от cache stampede: lock или probabilistic early expiration.

## Критерии приёмки
- [ ] Замер p50 / p95 до и после
- [ ] При недоступном Redis приложение работает (медленнее), а не падает
- [ ] Тест: после записи устаревшие данные из кэша не отдаются
