# T5.6 Файлы и изображения

**Фаза:** P5 · **Слой:** backend, frontend, infra · **Зависит от:** T5.3 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- S3-совместимое хранилище: MinIO локально, Cloudflare R2 или Supabase Storage на проде.
- Presigned PUT напрямую из браузера; подтверждение загрузки.
- Лимиты размера и MIME (проверка сигнатуры файла, не только расширения).
- Превью картинок задачей в очереди; очистка «сирот» по cron.

## Frontend
- Вставка картинки drag-and-drop и из буфера обмена, прогресс загрузки, блок `image`.

## Критерии приёмки
- [ ] Файл не проходит через API-сервер
- [ ] Приватный файл нельзя скачать без прав (подписанный GET с коротким TTL)
- [ ] Загрузка, брошенная на середине, не оставляет мусора навсегда
