# T5.2 Rate limiting

**Фаза:** P5 · **Слой:** backend, frontend, system-design · **Зависит от:** T5.1 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Token bucket на Lua-скрипте в Redis (атомарно).
- Лимиты по пользователю и IP, разные для логина / API / тяжёлых операций.
- Заголовки `RateLimit-*` и `Retry-After`; ответ 429 в Problem Details.

## Frontend
- При 429 — понятное сообщение; фоновые запросы (автосейв) повторяются после `Retry-After`.

## Критерии приёмки
- [ ] Нагрузочный скрипт упирается в лимит ровно по конфигу
- [ ] Несколько инстансов API делят один лимит
