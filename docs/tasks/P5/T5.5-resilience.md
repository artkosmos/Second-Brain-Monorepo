# T5.5 Устойчивость к отказам

**Фаза:** P5 · **Слой:** backend, system-design, python · **Зависит от:** T5.3 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Единый HTTP-клиент для внешних вызовов (email-провайдер, позже LLM) с таймаутами connect / read.
- Retry с экспоненциальным backoff + jitter только для идемпотентных операций (tenacity).
- Circuit breaker; bulkhead через `Semaphore`.
- DLQ для задач, исчерпавших ретраи, и команда перезапуска.

## Frontend
- Деградация: если фича недоступна — сообщение, остальное работает.

## Критерии приёмки
- [ ] Тест с фейковым провайдером, который «висит» или отдаёт 500: запросы API не копятся, breaker открывается и закрывается
- [ ] Задачи из DLQ можно перезапустить
