# T7.2 Presence и live-обновления

**Фаза:** P7 · **Слой:** backend, frontend · **Зависит от:** T7.1 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Presence в Redis: TTL-ключи, обновление по heartbeat.
- События изменения дерева и метаданных страницы из outbox отправляются в WS.

## Frontend
- Аватары «кто сейчас на странице».
- Live-обновление сайдбара и заголовков без перезагрузки.

## Критерии приёмки
- [ ] Закрыл вкладку → пропал из presence ≤ 30 с
- [ ] Свои изменения не дублируются эхом
