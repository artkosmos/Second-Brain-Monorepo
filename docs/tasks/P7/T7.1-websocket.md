# T7.1 WebSocket-шлюз

**Фаза:** P7 · **Слой:** backend, system-design · **Зависит от:** T5.1 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- `/ws` с auth по cookie при handshake и проверкой `Origin`.
- Подписки на каналы (`page:{id}`, `workspace:{id}`) с проверкой прав.
- Fan-out между инстансами через Redis pub/sub.
- Heartbeat / ping, лимит сообщений, закрытие соединения при отзыве сессии.

## Frontend
- Один общий WS-клиент с переподключением (backoff) и восстановлением подписок.
- При reconnect — `invalidateQueries`, чтобы догнать пропущенное.

## Критерии приёмки
- [ ] Событие с инстанса A доходит до клиента на инстансе B
- [ ] Обрыв сети не оставляет «зомби»-подписок на сервере
