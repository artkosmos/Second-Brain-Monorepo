# T7.3 Комментарии и уведомления

**Фаза:** P7 · **Слой:** backend, frontend · **Зависит от:** T7.1 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Комментарии к блоку, треды, resolve; упоминания пользователей.
- `notifications` (inbox) + счётчик непрочитанных.
- Доставка через WS; письмо-дайджест задачей в очереди для офлайн-пользователей.

## Frontend
- Подсветка блоков с комментариями, боковая панель тредов.
- Inbox с бейджем, «отметить прочитанным».

## Критерии приёмки
- [ ] Счётчик непрочитанных консистентен между вкладками
- [ ] Решение о судьбе комментариев при удалении блока описано и покрыто тестом
