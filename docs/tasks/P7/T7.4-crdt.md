# T7.4 Совместное редактирование (CRDT)

**Фаза:** P7 · **Слой:** backend, frontend, system-design · **Зависит от:** T7.2 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- ADR: CRDT (Yjs) vs OT vs блокировка блока на время редактирования.
- Провайдер синхронизации на `pycrdt` (y-protocol поверх WS).
- Хранение обновлений, периодическая компакция в снапшот.
- Синхронизация состояния CRDT с таблицей `blocks` (для поиска, экспорта, истории версий).

## Frontend
- Редактор на Yjs (TipTap или BlockNote + провайдер, совместимый с y-websocket).
- Курсоры других участников.

## Критерии приёмки
- [ ] Два браузера печатают в один абзац одновременно — без потерь
- [ ] Офлайн-правки сливаются после переподключения
