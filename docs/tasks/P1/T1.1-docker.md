# T1.1 Docker-образ API и локальный стек

**Фаза:** P1 · **Слой:** infra · **Зависит от:** T0.3 · **Размер:** M

## Цель
Маленький, безопасный, воспроизводимый образ API и одна команда для подъёма всего стека локально.

## Что сделать
1. `infra/docker/api.Dockerfile`, multi-stage:
   - builder: `ghcr.io/astral-sh/uv`, `uv sync --frozen --no-dev` в `/app/.venv`, кэш через `--mount=type=cache`;
   - runtime: `python:3.13-slim`, только `.venv` + `src`, пользователь не root, `HEALTHCHECK`.
2. Запуск: `uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8000 --proxy-headers`.
3. `.dockerignore`: тесты, `.env*`, кэши.
4. `infra/compose.yaml`: `postgres`, `api` (из Dockerfile), `migrate` (одноразовый `alembic upgrade head`; `api` ждёт его через `depends_on: condition: service_completed_successfully`), опционально `frontend`.
5. Замерить размер образа и записать в README.

## Критерии приёмки
- [ ] `docker compose -f infra/compose.yaml up` поднимает БД, мигрирует и запускает API
- [ ] Образ < 250 МБ, процесс не от root (`docker exec ... id`)
- [ ] Пересборка после правки кода (без изменения зависимостей) использует кэш слоя зависимостей

## Частые ошибки
| Антипаттерн | Почему плохо |
| ----------- | ------------ |
| `COPY . .` до установки зависимостей | любая правка кода сбрасывает кэш зависимостей |
| `.env` внутри образа | секрет в каждом слое и в registry |
