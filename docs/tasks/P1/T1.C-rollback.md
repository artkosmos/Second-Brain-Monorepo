# T1.C Challenge: учебный откат

**Фаза:** P1 · **Слой:** challenge · **Зависит от:** T1.4 · **Размер:** S

## Цель
Отработать откат плохого релиза до того, как он понадобится по-настоящему.

## Что сделать
1. Специально выкатить на staging релиз, который ломает `/notes` (не миграцией).
2. Найти проблему по Sentry и логам.
3. Откатить за < 5 минут: `fly releases` + rollback / rollback в Render / revert + деплой.
4. Записать runbook `docs/runbooks/rollback.md`.

## Вопрос на подумать
Что делать, если плохой релиз включал миграцию, удаляющую колонку? Ответ — в T10.2 (expand/contract).
