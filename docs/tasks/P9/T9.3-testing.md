# T9.3 Углублённое тестирование

**Фаза:** P9 · **Слой:** backend, frontend · **Зависит от:** P2 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- testcontainers (Postgres, Redis, MinIO) вместо ручного Docker.
- factory-boy или polyfactory для тестовых данных.
- hypothesis для fractional indexing, перемещений в дереве, фильтров баз.
- Тесты миграций: upgrade → downgrade → upgrade на снапшоте данных.
- Покрытие в CI.

## Frontend
- Playwright e2e ключевых сценариев (регистрация, создание страницы, шаринг) против docker-стека в CI.

## Критерии приёмки
- [ ] hypothesis нашёл хотя бы один реальный баг (или описано, как честно искали)
- [ ] e2e стабильны, без `sleep`
