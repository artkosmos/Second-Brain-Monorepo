# T9.4 Производительность и доступность фронта

**Фаза:** P9 · **Слой:** frontend · **Зависит от:** P2 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Frontend
- Виртуализация длинных страниц и таблиц; skeletons вместо спиннеров.
- Prefetch страницы при наведении в дереве; code splitting редактора.
- Lighthouse ≥ 90.
- a11y: axe в Playwright, проход только с клавиатуры, проверка скринридером (Orca / NVDA), контраст, `prefers-reduced-motion`.

## Backend
- Сжатие ответов, `ETag` на чтение страницы, HTTP-кэш для статики.

## Критерии приёмки
- [ ] Нет критичных нарушений axe
- [ ] Основные сценарии проходятся без мыши
