# T9.1 Метрики и трейсинг

**Фаза:** P9 · **Слой:** backend, infra · **Зависит от:** P1 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- OpenTelemetry: FastAPI, SQLAlchemy, Redis, httpx, воркер; проброс контекста трейса в фоновые задачи через outbox.
- Prometheus-метрики: RED (rate, errors, duration) по маршрутам, длина очереди, пул БД.
- Grafana-дашборд; SLO (например, 99% запросов страницы < 300 мс) и error budget.

## Frontend
- Web Vitals отправляются на бэкенд или в Sentry.

## Критерии приёмки
- [ ] Один трейс показывает путь «HTTP → SQL → outbox → воркер»
- [ ] Дашборд хранится в репо как код (JSON)
