# T4.C Challenge: Postgres RLS

**Фаза:** P4 · **Слой:** challenge · **Зависит от:** T4.2 · **Размер:** M

## Что сделать
- Включить Row Level Security на `pages` / `blocks` с политикой по `current_setting('app.workspace_id')`, который выставляется (`SET LOCAL`) в начале каждой транзакции.
- Показать тестом, что баг «забыли фильтр по workspace» в репозитории больше не приводит к утечке данных.
- Измерить накладные расходы RLS на типичных запросах.
- Учесть роль, под которой работают миграции (RLS их не должен ломать).
