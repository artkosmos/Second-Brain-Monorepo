# T4.5 Взрослая аутентификация

**Фаза:** P4 · **Слой:** backend, frontend, system-design · **Зависит от:** T4.1 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- Короткий access JWT + refresh-токен (opaque, в БД хранится хэш) с ротацией при каждом обновлении.
- Reuse detection: повторное использование старого refresh отзывает всю семью токенов.
- Список сессий (устройство, IP, последняя активность) и отзыв.
- CSRF для мутаций (double-submit token или проверка `Origin`).
- Rate limit на логин (пока in-memory, в T5.2 — Redis).
- Заменяет sliding-cookie из урока 19.

## Frontend
- Прозрачное обновление токена на 401 с единой очередью запросов (не 10 параллельных refresh).
- Страница «Активные сессии», «Выйти со всех устройств».

## Критерии приёмки
- [ ] Украденный и уже использованный refresh-токен убивает сессию
- [ ] Logout со всех устройств работает
- [ ] 10 параллельных запросов с истёкшим access → ровно один refresh
