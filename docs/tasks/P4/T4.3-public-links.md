# T4.3 Публичная ссылка

**Фаза:** P4 · **Слой:** backend, frontend · **Зависит от:** T4.2 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- `share_links` с криптостойким токеном (`secrets.token_urlsafe`), отзыв, срок действия.
- `GET /public/{token}` — read-only, без cookie.
- `Cache-Control` + `ETag`; заголовок `X-Robots-Tag: noindex` по умолчанию.

## Frontend
- Публичная страница рендерится на сервере (SSR / ISR).
- Переключатель «Опубликовать в веб», копирование ссылки.

## Критерии приёмки
- [ ] Отзыв ссылки → 404 сразу (учесть кэш)
- [ ] Решение, видны ли дочерние страницы по публичной ссылке, зафиксировано и покрыто тестом
