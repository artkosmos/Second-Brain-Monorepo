# T4.7 Security hardening по OWASP API Top 10

**Фаза:** P4 · **Слой:** backend, system-design · **Зависит от:** T4.5 · **Размер:** M

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Контекст
К концу P4 приложение многопользовательское. Безопасность до сих пор проверялась точечно (IDOR в тестах). Нужен системный чеклист, по которому каждый пункт закрыт кодом и тестом, а не фразой «мы помним».

## Что сделать
1. `docs/security.md`: таблица по [OWASP API Security Top 10 (2023)](https://owasp.org/API-Security/) — для каждого пункта: где закрыто в коде, какой тест это проверяет, что осознанно отложено (и до какой задачи).
2. **API1 BOLA / API5 BFLA:** параметризованный тест-набор «чужой ресурс → 404 / 403» для всех эндпоинтов с `{id}`; генерируется из списка роутов FastAPI, чтобы новый эндпоинт без теста падал в CI.
3. **API3 Property-level:** отдельные схемы на запись с allow-list полей (`extra="forbid"`); тест, что `role`, `owner_id`, `workspace_id` нельзя задать через body.
4. **API4 Resource consumption:** лимит размера тела (middleware), лимит глубины дерева и размера batch (T2.3), таймаут запроса, лимит на число элементов в `?ids=`.
5. **API8 Misconfiguration:** security headers middleware — `Strict-Transport-Security`, `Content-Security-Policy` (для API — минимальный, для фронта — через Next.js), `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`; CORS только с явным списком origin; `/docs` закрыт на проде или за авторизацией.
6. **API9 Inventory:** `openapi.json` в репо (T0.6) как единственный список эндпоинтов; эндпоинты без `operation_id` и тега падают в тесте.
7. Политика ошибок: 404 вместо 403 там, где само существование ресурса — секрет (решение задокументировать).
8. Pre-commit / CI: `bandit` или `ruff` правила `S*`; `zizmor` для GitHub Actions workflows.

## Критерии приёмки
- [ ] `docs/security.md` заполнен для всех 10 пунктов, каждый ссылается на тест или задачу
- [ ] Новый эндпоинт с `{id}` без authorization-теста роняет CI
- [ ] Тест: тело запроса 20 МБ → 413 до чтения в память
- [ ] Mozilla Observatory (или `securityheaders.com`) для staging — оценка не ниже B
- [ ] Mass assignment: `PATCH /users/me` с `{"role": "admin"}` → 422
