# T4.2 Права на странице с наследованием

**Фаза:** P4 · **Слой:** backend, frontend, system-design · **Зависит от:** T4.1 · **Размер:** L

> Короткая карточка. Подробное ТЗ пишется перед стартом фазы.

## Backend
- `page_permissions` (page, user или роль, уровень: view / comment / edit / full).
- Эффективное право = ближайший предок с явным правом (recursive CTE) или права workspace.
- Кэш вычисленных прав; инвалидация при move и изменении прав.

## Frontend
- Диалог «Поделиться»: добавить человека, уровень доступа, видно, откуда право унаследовано.

## Критерии приёмки
- [ ] Перенос страницы в другой раздел меняет эффективные права поддерева
- [ ] Тесты матрицы ролей и уровней
- [ ] Проверка прав на глубокой странице — фиксированное число запросов
